# R81

## A

读入`x`后判断即可
当然可以用if或者连续的三则运算符

## B

读入`n`, `s`, `t`之后，可以创建两个变量，分别表示从`s`到`t`要复制的文件夹个数和从`t`到`s`要复制的文件夹个数.
然后就可以`for`一遍，去查找有没有`s`有但`t`没有或者`t`有但`s`没有的。分别去+1
最后输出这两个的`max`值即可。

## C

这道题的思路就是去差分+前缀和一次搞定
首先输入掉`n`和`m`，然后依次读入`p, d, t`（OS：这里其实不用开三个数组，只需三个变量）
然后这里特判一下`t = 0`的情况

- `t = 0` ? 给第一个位置加上折扣价，`continue`;
- `t != 0` ? 给第一个位置加上原价，在第`t + 1`个位置减掉原价加上折扣价，完事
然后做个前缀和即可
最后输出前缀和数组`Ans`即可

注意：一定要开`long long`，不开`long long`的结果是第6个过不去！

时间复杂度`O(n + m)`.
